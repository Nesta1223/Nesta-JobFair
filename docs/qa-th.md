# คำถามซ้อมตอบ

**ทำไมเลือก MongoDB?** Assignment 7 และบท 07–09 ใช้ Mongoose อยู่แล้ว และโจทย์อนุญาต MongoDB Atlas จึงต่อยอด schema, reference และ populate เดิมได้โดยไม่เปลี่ยน framework

**Authentication ต่างจาก Authorization อย่างไร?** Authentication ตรวจว่าเป็นใครจาก JWT ส่วน Authorization ตรวจ role หรือเจ้าของรายการก่อนอนุญาตให้เข้าถึงข้อมูล

**ทำไมไม่รับ user ID จาก body?** Client แก้ request body ได้ จึงต้องใช้ `req.user.id` หลังตรวจ token แล้ว และไม่เปิดให้เปลี่ยนเจ้าของผ่านการ update

**JWT เก็บอะไร?** เก็บ ID ของผู้ใช้และข้อมูลเวลา ไม่เก็บรหัสผ่าน ระบบตรวจลายเซ็นและตรวจว่าบัญชียังมีอยู่ก่อนดำเนินการต่อ

**bcrypt ทำงานตอนไหน?** ทำงานใน pre-save hook เมื่อรหัสผ่านเปลี่ยน ใช้ salt 10 rounds ตอน login ใช้ `bcrypt.compare` เปรียบเทียบ ไม่ได้ถอดรหัส hash กลับมา

**Logout แล้ว JWT เดิมยังใช้ได้ไหม?** วิธีใน Chapter 12 เคลียร์ cookie และ token ที่ client ไม่ได้ revoke JWT ที่คัดลอกไว้ก่อนหน้า ดังนั้น JWT เดิมยังใช้ได้จนหมดอายุ หากต้องการเพิกถอนจริงต้องมีระบบเพิ่มเติม

**ทำไมวันที่เป็นปี 2022?** เอกสาร Project 3 ระบุวันที่ 10–13 พฤษภาคม 2022 จึงใช้ตามเอกสารและไม่เปลี่ยนปีเอง

**จัดการ timezone อย่างไร?** รับเฉพาะ `YYYY-MM-DD` แล้วเก็บเป็น UTC midnight ตอนส่งออกใช้ส่วนวันที่โดยตรง จึงไม่แปลงวันตาม timezone ของเครื่องที่เปิดไฟล์

**ส่งหลายคำขอพร้อมกันจะเกิน 3 รายการไหม?** มี slot ภายในหมายเลข 1–3 และ unique index ของ `(user, slot)` หากคำขอชนกันจะอ่านสถานะใหม่แล้วลองอีกครั้ง ชุดทดสอบส่ง 8 คำขอพร้อมกัน ได้ 201 จำนวน 3 ครั้ง และ 400 จำนวน 5 ครั้ง

**populate คืออะไร?** อ่าน Company ผ่าน ObjectId reference แล้วรวมฟิลด์ที่เลือกใน response โดยไม่ได้เก็บข้อมูลบริษัทซ้ำทั้งก้อนใน Booking

**ทำไมต้องตรวจว่าบริษัทมีจริง?** Mongoose reference ไม่ได้บังคับให้ข้อมูลปลายทางมีอยู่แบบ foreign key ของฐานข้อมูลเชิงสัมพันธ์ จึงต้องตรวจใน controller

**401 กับ 403 ต่างกันอย่างไร?** 401 คือยังไม่ผ่านการยืนยันตัวตน ส่วน 403 คือยืนยันแล้ว แต่ไม่มีสิทธิ์เข้าถึงรายการนั้น

**CSV ป้องกันข้อมูลผิดรูปแบบอย่างไร?** กรองเจ้าของก่อนส่งออก ครอบค่าและ escape เครื่องหมาย quote เพื่อรองรับ comma และ newline รวมทั้งเติม apostrophe หน้าค่าที่ขึ้นต้นเหมือนสูตร spreadsheet

**ผลทดสอบเวลา 3 วินาทีพิสูจน์อะไร?** เป็นเวลาที่วัดบน localhost กับ MongoDB ชั่วคราวเท่านั้น ไม่ใช่ load test และไม่ได้รับรองเวลา Atlas หรืออินเทอร์เน็ตในทุกสภาพแวดล้อม

**ส่วนใดมาจากบทเรียน และส่วนใดต่อยอด?** Express, Mongoose, JWT, bcrypt, protect, populate, ownership และ Postman มาจากบทเรียน ส่วนการตรวจวันที่แบบเข้มงวด การจำกัดฟิลด์ที่แก้ได้ unique index สำหรับโควตา และ CSV เป็นส่วนต่อยอดที่มีการทดสอบกำกับ
